1. Data Management and Analysis (Microsoft Excel)

2. Database Development (Microsoft Access)

What I can do: Create relational databases, design tables and run basic queries to retrieve the records I need.

Evidence in brief: Relational tables and basic select queries built as part of my first-year database practice; see the Academic Projects and Experience section of my CV.
